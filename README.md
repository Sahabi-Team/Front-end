# 🏋️‍♂️ Gymbato

**Gymbato** is a web-based platform designed to connect users with personal fitness coaches. It offers features such as personalized workout programs, free body analysis tools, and real-time chat with coaches — all in one place.

---

## 🚀 Features

- 🧠 Smart body analysis (BMI, BFP, etc.)
- 🏋️ Personalized workout plans based on user goals
- 📩 Direct chat with trainers
- 🔍 Browse and select coaches based on specialty and experience
- 📱 Responsive design for mobile and desktop

---

## 🧑‍💻 Tech Stack

### Frontend
- React.js
- Figma (for UI/UX Design)
- MUI (Material-UI)

### Backend
- Django / PostgreSQL 

---

## 🎯 Project Goals

- Gain practical experience in UI/UX design with Figma
- Implement scalable, maintainable frontend code with React
